# 特斯拉 Model 3/Y CAN 信号数据库

可筛选、可收藏的特斯拉 Model 3/Y CAN 信号浏览网站，数据汇总自 31 个公开出处（GitHub DBC 仓库、公开论坛、技术博客、厂商文档等），共 13,282 条信号。

- 在线筛选：关键词、CAN ID（支持 0x370 或 880）、字节序、Juniper 适用性、版本差异、修正建议
- 收藏：点击 ★ 收藏信号，收藏数据保存在浏览器本地 IndexedDB
- 悬浮按钮打开收藏列表，按 CAN ID 分组排序，可导出 CSV / JSON
- 出处清单页：每个来源的渠道类型、链接、许可证

部署：GitHub Pages（静态页面，无构建步骤）。

数据说明：所有信号定义均为社区逆向工程资料，非特斯拉官方规范；各出处许可证见站内「出处清单」页。
